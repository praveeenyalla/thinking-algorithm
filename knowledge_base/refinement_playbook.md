# Refinement Playbook

Refinement is a single improvement pass applied after evaluation.

The goal is to strengthen an answer without changing the problem being solved.

A good refinement should:

- preserve the original perspective
- respond directly to evaluation feedback
- add clearer reasoning where the answer is vague
- add more concrete action where the answer is weak on usefulness
- make success criteria visible

Refinement is not a loop in this version. It happens once, then the system re-evaluates and compares.
