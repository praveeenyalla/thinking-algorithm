# Fine-Grained Rubric Evaluation

Good evaluation is not only generic helpfulness.

Use a custom rubric with named criteria and explicit score meaning.

Recommended criteria for this project:

- correctness: does the answer stay aligned with the problem?
- clarity: is the answer understandable and direct?
- usefulness: does the answer help the user make progress?

Fine-grained rubrics give more reproducible judgment than a single vague preference score.
